# 🏨 Grand Luxe - Resort Management System

A modern, full-stack Resort Management System built with **Node.js, Express, HTML5, CSS3 (Glassmorphism), and JavaScript (ES6)**.

---

## ✨ Features
* **Concurrency Locking Engine:** Prevents duplicate/double bookings for occupied rooms.
* **Front Desk Operations:** Instant Check-In & Check-Out management.
* **Housekeeping Console:** Live updates on room cleanliness status.
* **POS & Dining Integration:** Room service ordering directly linked to total revenue.
* **Real-time Analytics:** Automated occupancy rate and total revenue calculation.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Backend:** Node.js, Express.js
* **Architecture:** REST APIs
